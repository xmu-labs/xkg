## Relationship

- xkg: the restrained knowledge-layer saddle derived from the central void of XMU.
- xkg has sparse optional surface nodes, no center node, Sora headings + Inter UI.
- XKG's Lunar Graphite palette is distinct from XMU's Cosmic Blue.

## Source geometry caveat
The candidate Bézier outline was manually traced from the flattened XMU 2D branding-board reference; the original XMU master is not available in this repository. The shared path is identical across all four flat logo versions; it is an approximate match to the original artwork. **Do not claim exact mathematical/pixel geometric fit.** Final artwork must be compared to the real XMU master and reapproved.
